# Personal Portfolio — Kyomuhendo Isihaka

A cinematic, animation-driven personal portfolio website for **Kyomuhendo Isihaka**, focused on backend engineering, digital products and modern interactive web experiences.

## Overview

This project is a custom single-page portfolio built from scratch with HTML, CSS and JavaScript. It uses motion, scroll-linked storytelling, technical visual language and a dark interface to present engineering work in a more distinctive way than a standard résumé-style website.

## Highlights

- Animated intro sequence
- Fixed glass-style navigation
- Responsive hero section
- Scroll-synchronised storytelling section
- Interactive technical/network visuals
- Smooth transitions and motion effects
- Responsive layout for desktop and mobile
- Custom developer branding and typography
- Lightweight static architecture with no framework requirement

## Tech Stack

- **HTML5**
- **CSS3**
- **JavaScript**
- **Anime.js**
- **SVG**
- **Responsive Web Design**

## Run Locally

Because the project is static, you can run it with any basic HTTP server.

```bash
git clone https://github.com/Kyomuhendo-Isihaka/mypotifolio.git
cd mypotifolio
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

You can also open `index.html` directly in a modern browser for most functionality.

## Design Direction

The interface uses a dark engineering aesthetic with monospace accents, animated system diagrams, scroll-based transitions and a restrained visual hierarchy. The goal is to make the portfolio feel like an interactive product rather than a static developer profile.
